# Проверка версии 0.1

Дата: 05.11.2026.

## Автоматически

`npm run check` прошёл для корня сайта и для `BASE_PATH=/turysamara`.

- 54 HTML-страницы, 153 уникальных запроса.
- Единственный владелец каждого назначенного запроса; явное решение для всех остальных.
- Сохранены 49 строк с пустыми частотами, реальные нули и 46 отмеченных несоответствий частот.
- Уникальные Title, Description и URL; один H1 в содержимом каждой страницы.
- Проверены 2 429 локальных ссылок и 177 ссылок на изображения.
- JSON-LD синтаксически валиден; нет выдуманных цен и AggregateRating.
- Review noindex, отсутствие canonical в review, пустой неанонсируемый sitemap.
- У каждой страницы собственный SEO-паспорт; отдельный паспорт у 404.
- Production-сборка отклоняется, пока не подтверждены факты и готовность интеграций.

## В браузере

- Главная на настольной ширине: просмотрена; исправлены экранированные стрелки и высота фото.
- Компоновка на ширине 390 px проверена во встроенном узком окне; мобильное меню открывается и обновляет aria-expanded. Это проверка CSS-ширины, не реальный телефон.
- SEO-паспорт открывается/закрывается; сверка Title, Description, H1, robots и OG показывает совпадение HTML с заданными значениями, а нерешённые пункты отмечены как требующие проверки.
- Поиск «Ширяево» выводит шесть релевантных разделов и программ.
- Карточка добавляется в план, выбор отображается в списке.
- Форма с тестовыми данными готовит черновик и включает выбранную программу. Письмо не отправлялось.
- Фильтр «По Волге» + поиск «Ширяево» оставляет соответствующую карточку.

## Не измерено / не подключено

Реальная мобильная производительность, Lighthouse/CWV, индекс поисковиков, серверные редиректы основного домена, CRM, оплата, SMS, доставка заявок, реальный календарь, остатки мест и отзывы. Первый ручной GitHub Pages workflow не запускался. Для выбранной пользователем настройки main → /(root) добавлен экспорт готовых HTML-файлов в корень; дальнейшая публикация выполняется GitHub Pages из ветки.

## Публикация из ветки

`npm run build:pages` собирает и проверяет review-версию с BASE_PATH=/turysamara, экспортирует HTML, изображения, скрипты и .nojekyll в корень. Внутренние ссылки используют путь проекта. noindex сохранён.

## Вкладка контекстной рекламы

Добавлена `/reklama/` и заметная ссылка в верхней панели всех страниц review. Проверена в браузере: переход с главной, содержание предложения, переход к стоимости. Сборка: 55 страниц, 2 519 локальных ссылок, 178 ссылок на изображения. Цены и сроки отмечены для согласования. Страница исключена из туристического поиска; production-сборка фильтрует reviewOnly.

## Стоимость контекстной рекламы — 06.11.2026

По указанию Юрия установлена единая цена под ключ: 30 000 ₽ в месяц. Подготовка, запуск, ведение и аналитика включены; рекламный бюджет отдельно. Убрано требование согласовать стоимость услуг из паспорта и карты страниц. Обновлены описание, первый экран, блок стоимости и выгрузки.

## Клиентский просмотр без выдачи файлов — 06.11.2026

Удалены кнопки скачивания на `/seo/`, экспорт паспортов JSON и генерация `review/` в опубликованной сборке. Экспортёр удаляет пять прежних файлов review из корня. Из встроенного JSON паспорта убраны полные тексты и семантика; просмотр SEO сохранён. Проверки сборки запрещают повторное появление выгрузок и кнопок скачивания. Публичный репозиторий и видимое содержимое страниц не защищены от копирования.
