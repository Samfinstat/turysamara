# Город-Курорт · turysamara

Рабочий SEO-прототип нового сайта для согласования с клиентом. **Подготовлен для публикации из `main → /(root)`.** Целевой домен: https://gorod-kurort.com. Текущее состояние: 5 ноября 2026.

Сайт генерируется в обычные HTML-страницы: содержание, метаданные, ссылки и JSON-LD присутствуют без выполнения JavaScript. База — ТЗ клиента, 153 запроса из выгрузки Topvisor и выборочная проверка действующего сайта.

## Что подготовлено

- 54 страницы, включая служебные и 404. Навигация из ТЗ, разделы по спросу, карточки реальных программ, блог и служебные страницы.
- Для каждой страницы: Title, Description, H1/H2/H3, вводный текст, содержательные блоки, контекстные ссылки, OG, схема данных и SEO-паспорт.
- Все 153 запроса: 98 назначены, 7 назначены условно, 36 в резерве, 8 исключены как чужие бренды, 4 относятся к цифровому контенту без подтверждённого продукта.
- Рабочие поиск, фильтры каталога, мобильное меню, план поездки и подготовка письма. Автоматической отправки, списаний и записи на даты нет.
- Кнопка «SEO страницы» и общая карта `/seo/` с выгрузками структуры, текстов, ключей и технических требований.
- Режим review: noindex на всех страницах. Он **не закрывает доступ**; репозиторий публичный. Для приватного просмотра нужен хостинг с авторизацией.

## Посмотреть локально

Нужен Node.js 22+. Внешних npm-зависимостей нет.

```sh
npm run dev
```

Открыть http://localhost:3000. Сборка: `npm run build`. Проверки: `npm test` после сборки, либо `npm run check`.

## Просмотр через main → /(root)

В **Settings → Pages** выбрать:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/(root)**.

Готовый `index.html`, разделы и ресурсы уже находятся в корне. `.nojekyll` отключает обработку Jekyll. После коммита GitHub Pages публикует эту демонстрационную версию автоматически.

Адрес: https://samfinstat.github.io/turysamara/

Все страницы остаются `noindex`. Основной домен `gorod-kurort.com` не переключается.

### Обновить содержимое

Редактируйте исходники в `data/`, `public/` и `scripts/`, затем выполните:

```sh
npm run build:pages
```

Команда собирает версию с путём `/turysamara`, проверяет её и копирует готовые файлы в корень. Отправляйте исходники и результат одним коммитом в `main`. Список созданных файлов хранится в `.pages-manifest.json`; вручную изменённый файл не перезаписывается молча.

`npm run build` и `npm run dev` по-прежнему работают только с `dist/` для локального просмотра. Ручной workflow **Preview on GitHub Pages** оставлен как альтернативный вариант; для выбранного режима публикации из ветки запускать его не требуется.

## Где редактировать

| Файл | Назначение |
|---|---|
| `data/pages.json` | Структура, все тексты, H1, H2/H3, связи, карточки, вопросы по каждой странице |
| `data/semantics.json` | 153 исходных запроса, все пять частотностей, решения и владельцы |
| `data/site.json` | Контакты, навигация, домен, состояние подключения |
| `data/assets.json` | Фотографии, размеры и ссылки на источник |
| `scripts/build.mjs` | Статическая генерация, SEO-поля, JSON-LD и экспорт |
| `public/assets/style.css` | Адаптивный дизайн |
| `public/assets/app.js` | Поиск, фильтры, план поездки, форма, SEO-инспектор |
| `docs/structure.md` | Обоснование структуры и спорные кластеры |
| `docs/technical-seo.md` | Техническое SEO |
| `docs/launch-checklist.md` | Что нужно подтвердить и подключить перед коммерческим запуском |
| `docs/query-map.csv` | Таблица запросов для Excel / Topvisor |
| `docs/sources.md` | Источники и границы проверки |

После сборки `dist/review/` содержит `structure.csv`, `query-map.csv`, `content.txt`, `manifest.json`, `technical-seo.txt`. Их можно скачать также со страницы `/seo/`.

## Важные ограничения первой версии

Частотности — Яндекс **без региона**, дата измерения неизвестна. Это ручная группировка по смыслу; региональная SERP-кластеризация ещё не выполнена. Пропуски не заменены нулями.

Точные даты, места, цены, возраст, длительность, условия возврата, реквизиты и правила лояльности не предоставлены в едином подтверждённом виде. Часть данных старого сайта противоречива. Поэтому платежи, SMS, виджет отзывов, CRM и аналитика не имитируются. Тексты — редакционный проект, нуждающийся в согласовании фактов.

Техническая защита запрещает production-сборку до заполнения флагов готовности в `data/site.json`. Даже после этого в sitemap входят только страницы с `publishReady: true`. Это не автоматическая гарантия качества: выполните чек-лист запуска. В режиме production рабочая SEO-карта и кнопки инспектора отключены.

Директ: коммерческую презентацию, стоимость и стратегию добавляем отдельным этапом после SEO-основы, по согласованным исходным данным.
